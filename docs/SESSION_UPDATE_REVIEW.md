# 대화 맥락과 이미지 버전 변경 검토

이 문서는 세션 버전 기능을 적용한 당시의 검증 기록이다. 이후 모델별 생성 기본값,
thinking 예산과 최신 스키마만 지원하도록 바뀐 현재 설계는 [TECH.md](TECH.md)를 참고한다.
아래의 DB 마이그레이션 구현과 검증은 이후 요구사항 변경으로 제거되었다.

사용자의 최신 요구에 따라 `SPEC.md`와 `TECH.md`의 기존 세션 내부 Fork 설계를
대화 행별 이미지 버전과 독립 세션 복사로 변경했다. 원본 이미지와 생성 설정은
불변 기록으로 유지한다. UI 또는 추론 런타임이 세션 복사 규칙을 결정하지 않는다.

| 요구 | 구현 및 검증 |
| --- | --- |
| 이전 요청 n개 참고 | 기본 4개, 고급 설정 0~20개. 요청/선택된 프롬프트의 user/assistant 쌍을 전달한다. 최근 맥락, 이력 비활성화, 재시도의 원래 기준 유지 테스트 |
| 토큰 한도 내 맥락 | 채팅 템플릿과 tokenizer로 계산하고 출력 용량을 확보한다. 오래된 완전한 쌍부터 제외한다. 현재 기준/요청 초과 시 명시적 오류 테스트 |
| placeholder에 프롬프트 통합 | canvas 안에서 thinking/프롬프트 표시. UI 테스트와 실제 숨겨진 WebView2의 구조 확인 및 PNG 캡처 |
| 맨 아래로 버튼 | 위로 스크롤하면 입력창 중앙 상단에 표시. 클릭 시 즉시 이동하고 자동 따라가기 복원. 읽는 위치 유지 UI 테스트와 WebView2 위치/동작 확인 |
| 다시/직접 수정 생성 | LLM 우회, 현재 생성 설정 사용, 원래 turn_id의 버전 추가. 생성 중/실패/재시도도 해당 행에 표시. 서비스와 UI 테스트 |
| 좌우 버전 탐색 | 해당 행만 변경하며 다른 대화 행은 보존. 선택한 버전이 다음 수정 기준이고 재시작 후 복원. 서비스/복원/UI 테스트 |
| 분기 버튼으로 세션 복사 | 선택 행까지 새 ID의 요청/이미지 기록 복사. 이전 행 버전/선택 상태 보존, 목표 행은 선택 이미지만 복사. PNG는 불변 파일을 공유. 복사 실패 전체 rollback 테스트 |
| 기존 DB 보존 | turn_id와 turns 추가 및 수동 생성의 버전 연결. ALTER TABLE 전에 transaction을 시작하여 실패 시 스키마까지 rollback하고 다음 실행에 재시도. 마이그레이션/재시도 테스트 |
| 영어 이미지 프롬프트 지침 | 특정 모델 이름 없이 이미지 생성 역할을 설명. 최신 요청 우선, 현재 프롬프트 보존, 관련 태그/관계 묘사 혼합. 비라틴 문자 최종 출력은 이미지 엔진에 전달하지 않는 테스트 |

지침은 [모델 제작자의 공식 가이드](https://huggingface.co/circlestone-labs/Anima#prompting)를
참고해 소문자 태그, 공백 표기, subject count, 요청된 artist의 @ 접두사,
다중 인물의 외형/위치 연결과 Aesthetic의 score 태그 제외를 반영했다.
품질 태그를 무조건 나열하거나 요청하지 않은 rating/style을 강제하지 않는다.

자동 검증은 모델·GPU·네트워크 없이 Python 148개, UI 29개, Ruff,
TypeScript와 Vite build를 통과했다. 별도 WebView2 검사 결과는
`build/session-review/report.json`, 생성 영역 캡처는
`build/session-review/in-place-generation.png`에 있다.

이번 작업에서 실제 모델 추론과 모델 다운로드는 실행하지 않았다.
지침과 데이터 전달, UI/저장 동작의 검증이며 생성 이미지의 품질 향상을
실제 GPU 비교로 검증했다고 주장하지 않는다.
