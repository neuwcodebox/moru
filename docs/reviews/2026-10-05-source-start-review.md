- README의 시작하기를 GitHub 저장소 복제, 추론 의존성 설치, ComfyUI 준비, React UI 빌드, 앱 실행 순서로 바꿨다.
- 영어·한국어 README의 포터블 ZIP 안내에 사용자가 제공한 Google Drive 다운로드 링크를 추가했다.
- 최초 준비와 이후 실행 명령을 구분하고, 필요한 도구와 모델 준비 및 저장 위치를 안내했다.
- 명령을 pyproject.toml, frontend/package.json, Vite의 Node.js 요구사항, scripts/setup_comfyui.py, 앱 진입점 및 TECH.md와 대조했다.

- ZIP 링크가 두 README의 해당 절에 동일하게 들어가는지와 diff 공백 검사를 확인했다. Drive의 공개 접근 권한과 ZIP 내용은 검증하지 못했다.
