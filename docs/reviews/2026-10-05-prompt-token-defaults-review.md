# 프롬프트 LLM 토큰 기본값 검토

기본 컨텍스트를 4096, 출력 한도를 2048토큰으로 늘렸다. Thinking 켜짐과
추론 수준 보통은 유지하며, 최종 프롬프트 예약 640토큰을 제외한 추론 예산은
낮음 704, 보통 1056, 높음 1408토큰이다. 입력에는 2048토큰을 확보한다.
저장된 사용자 설정은 자동 전환하지 않으며 이전 2048/1024 설정을 보존하는
회귀 테스트를 추가했다. 기존 앱에서는 고급 설정에서 직접 변경할 수 있다.

도메인의 기본값을 UI에 전달하는 기존 구조를 유지했다. 설정 변경·저장 테스트와
portable smoke 검사도 새 기본값과 구분되는 8192/4096 값으로 갱신했다.
SPEC, TECH, 프롬프트 가이드의 현재 값은 맞추고 README와 과거 검토 기록은 유지했다.

- 변경 전 새 기본값·추론 예산 테스트 4개가 실패하고 변경 후 통과하는 것을 확인했다.
- 관련 Python 테스트 111개, 전체 일반 테스트 187개와 Ruff 검사를 통과했다.
- 프런트엔드 테스트 57개, TypeScript 검사와 프로덕션 빌드를 통과했다.
- 모델/GPU 추론과 데스크톱 앱 실행 검증, portable ZIP 재빌드는 수행하지 않았다.
