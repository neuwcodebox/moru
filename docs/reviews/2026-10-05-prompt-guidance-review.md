# 프롬프트 작성 지침 조사·적용 검토

## 문제와 범위

4B 프롬프트 LLM에 역할과 간단한 금지 사항만 전달하던 지침을,
이미지 프롬프트의 구조·태그 선택·대상별 속성 연결·수정 방법을 가르치는 지침으로 바꾼다.
일반적인 Stable Diffusion 팁을 현재 이미지 엔진에 무조건 적용하지 않는다.
모델명은 LLM 지침에 넣지 않는다.

조사 자료와 작성 예시는 [프롬프트 작성 지침](../PROMPT_GUIDE.md)에 정리했다.
제작자 문서를 우선하고, 태그의 실제 빈도 순위는 조사하거나 주장하지 않았다.
웹 검색에는 일반적인 작성 방법만 사용했으며 사용자 요청이나 이력을 전송하지 않았다.

## 구현

- `prompt_instructions.py`에 출력·요청 해석·구성·태그 선택·검토 규칙을 모았다.
  CUDA 로딩·추론·스트림 처리와 지침의 변경 이유를 분리했다.
- 생성에는 동물 수와 여러 인물의 속성 연결 예시를, 수정에는 기존 상태를
  유지하면서 시간만 바꾸는 예시를 붙인다. 공통 규칙은 공유한다.
- 예시는 system 내부에만 넣는다. 실제 이력을 가상의 예시 턴으로 대체하거나
  이력 슬롯을 예시로 소비하지 않는다.
- 소문자·공백 태그, 사람 수와 동물 수의 구분, 고유명사 영문 표기,
  상충하는 묘사의 교체, 불확실한 태그 대신 자연어 사용을 설명한다.
- 작가·등급 태그는 요청한 경우에만 사용한다. Aesthetic의 점수 태그 제외는 유지한다.
- 첫 실제 출력에서 태그 반복과 요청하지 않은 스타일·조명 추가가 발견돼,
  수를 반복 태그로 표현하지 않는 규칙과 예시 뒤의 요청 범위 확인 규칙을 보강했다.
- 기본 설정과 저장된 사용자 설정은 변경하지 않았다.

외부 검색·태그 API·검색 인덱스·추가 의존성·새 출력 파서는 도입하지 않았다.
README에 기능별 상세 내용을 추가하지 않았다.

## 검증 방법

단위 테스트는 전달되는 지침의 구조, 태그 선택표가 프리셋이 아니라는 규칙,
대상별 속성 연결, 생성·수정 예시의 구분과 실제 이력 보존을 확인한다.
모델의 의미 보존을 일반 단위 테스트의 문자열 스냅샷으로 대체하지 않는다.

실제 HauhauCS Qwen3.5-4B Uncensored Aggressive Q4_K_M의 토크나이저와
GGUF 채팅 템플릿으로 입력 예산을 확인하고 실제 추론 출력을 읽어 검토했다.
실행 중인 `E:\Utils\Moru`가 GPU를 사용하고 있어 비교 추론만 명시적으로 CPU에서
수행했다. production의 CUDA 전용 로딩이나 실행 중 앱은 변경하지 않았다.
검토 설정은 context 2048 / 출력 1024 / thinking 켜짐 / low이며 seed 1234를 사용했다.
CPU 검토는 별도 생성 함수 주입으로 수행했으며 CPU로의 자동 fallback을 추가하지 않았다.
이미지 엔진 추론·이미지 품질·CUDA 성능은 이번 검증 범위에 포함하지 않았다.

초기 전후 비교의 기준은 `0e2f419`의 지침이다.
동물 요청에서는 기존 지침이 실사 스타일·조명·8K를 추가한 반면 새 지침은
요청한 장면을 묘사했다. 다만 초기 새 출력도 고양이 태그를 반복했다.
여러 인물의 속성·관계는 새 출력에 표현됐지만 초기에는 요청하지 않은
실내·조명·매체가 추가됐다. 이 결과를 근거로 마지막 확인 규칙을 보강했다.
낮을 밤으로 변경하는 수정은 새 지침에서 개·목도리·눈·자세를 유지한 전체
프롬프트로 반환됐다. 기존 지침은 `daytime -> night`와 변경 사유를 출력했다.
이 비교는 소수의 고정 요청을 관찰한 것이며 통계적인 품질 개선율을 뜻하지 않는다.

초기 비교 결과는 `build/prompt-guidance-review/report.json`,
최종 지침의 별도 요청 샘플은 `build/prompt-guidance-review/final-report.json`에 저장한다.
생성한 검토 파일은 커밋하지 않는다. 재실행 가능한 GPU 샘플 스크립트는
`scripts/smoke_prompt_guidance.py`에 둔다.

## 최종 샘플 결과

| 요청 | 확인한 결과 | 남은 관찰 사항 |
| --- | --- | --- |
| 흰 토끼 세 마리와 당근, 사람 없음 | 문장에 수·털 색·당근·자는 행동을 표현하고 인물을 추가하지 않았다. 동일한 태그를 반복해 수를 표현하지 않았다. | 당근 색·지면·귀 등 부가 묘사가 있다. |
| 두 인물의 머리·옷 색, 좌우 위치, 우산 전달 | 두 인물의 수·외모·옷·위치·전달 방향을 표현했다. 요청하지 않은 실사·영화적 매체·조명은 추가하지 않았다. | 공통 태그에도 두 머리색을 나열했고, 우산을 어깨에 걸치는 동작·시선 등 부가 표현을 추가했다. |
| 안개 낀 호수와 소나무 숲, 수채화, 사람 없음 | 요청한 매체·환경·사람 없음 조건을 표현했다. | 반사·구름·분위기를 추가했다. |
| 소파 색만 초록에서 파랑으로 변경 | 고양이 수·검은 털·자는 행동·사람 없음 조건을 유지한 전체 프롬프트를 반환했다. | 색을 바꾸는 데 불필요한 대상은 추가하지 않았다. |

최종 샘플 4개는 모두 한 문단의 영어 프롬프트로 완료됐다.
작은 모델이 지침의 모든 금지 사항을 일관되게 지킨다고 결론 내리지는 않는다.
특히 대상별 속성 연결은 자연어에 표현됐지만 공통 외모 태그 사용과 부가 묘사는
남아 있다. 이미지에서 속성이 실제로 올바르게 반영되는지는 따로 검증해야 한다.

동일한 네 요청을 Turbo/Aesthetic 지침과 thinking 켜짐/꺼짐 템플릿으로
토큰화한 입력은 807~844토큰이다. 기본 입력 예산 1024 안에 들어가며
180~217토큰의 여유가 있다. 이 수치는 짧은 네 요청의 측정값이지
모든 누적 프롬프트와 이력이 들어간다는 보장이 아니다.
출력 공간 예약·오래된 쌍 제거·기준 상태와 최신 요청 보존 규칙은 변경하지 않았다.

실제 추론 결과는 일반 pytest의 통과 개수에 포함하지 않았다.
