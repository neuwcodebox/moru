# 실패 아이콘 장식 제거

## 변경

사용자 요청에 따라 실패·중지 아이콘을 감싸던 둥근 사각형 테두리와 배경을 제거했다.
아이콘 영역을 56×56px에서 아이콘 자체 크기인 28×28px로 줄였다.
오류 메시지와 재시도 버튼을 포함한 중앙 정렬, placeholder 색상과 재시도 동작은 유지한다.
SPEC.md에 아이콘 표시 규칙을 반영했다. 현재 TECH.md의 구조와 일치하며 별도 구조 변경은 없다.

## 검증

- 프런트엔드 테스트 91개, TypeScript 검사, production build 통과.
- CSS 장식만 변경했으므로 구현 선택자를 고정하는 단위 테스트를 추가하지 않고
  실제 WebView2의 1080×900 창에서 세로·가로 placeholder를 캡처해 직접 확인했다.
- 아이콘·문구·버튼 묶음의 가로·세로 중앙 오차 1 CSS px 미만,
  콘텐츠 넘침과 하단 오류 배너 중복 없음.
- diff 공백 검사 통과.

갱신된 화면은 `build/failure-ui-1080x900/portrait.png`, `landscape.png`에 있다.
화면 밖 테스트 창과 합성 오류 데이터만 사용했으며 모델 추론은 실행하지 않았다.
빌드·캡처 생성 파일은 커밋 대상에 포함하지 않는다.
