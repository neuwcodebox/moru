# 이미지 부분 편집 구현 및 검토

- 이미지별 편집은 프롬프트/영역 탭과 같은 행의 불변 이미지 버전을 사용한다. 초안·마지막 탭·원본 좌표계 도구 동작은 [SPEC 19절](../SPEC.md#19-영역-수정), 작성·추론·이력 경계는 [TECH](../TECH.md#영역-수정), 문구 작성 규칙은 [프롬프트 작성 지침](../PROMPT_GUIDE.md)을 따른다.
- 영역 작성은 장면과 수정 요청에서 선택 내용의 Anima용 쉼표 구분 영어 태그를 작성하고, 필수 속성·관계만 짧은 문장으로 보완한다. 전체 작성은 그 결과를 참고해 후속 대화용 장면을 작성한다. 일반 생성·대화 수정·영역 수정 지침은 역할·입력·출력과 범위가 명시된 예시로 구성하며 공통 형식은 영어 프롬프트 본문 한 문단이다. 로컬과 ChatGPT의 태그 검색·진행·소스 저장은 프롬프트 제공자의 공통 추론 경로를 사용한다.
- 검증: Python 전체 704개와 Ruff, 프론트엔드 타입 검사와 테스트 200개 통과. 태그 우선 작성 지침·예시, 두 제공자의 태그 응답 전달·진행 표시, 작성 역할·텍스트 형식·예시 경계, 검색 on/off·조회 실패·소스 저장·취소, 이력·분기·합성·일반 생성, 편집 초안·탭·붓·뷰 조작을 확인했다. 커밋 정리 과정에서 모델/GPU·빌드는 실행하지 않았다.
- 모델 확인 기록: RTX 3060, Qwen3.5 4B Q4_K_M, 컨텍스트 4096·출력 2048·thinking medium·시드 42에서 표정 변경과 실제 단보루 조회(후보 8개), 세 번의 작성 추론, 진행·소스·미리보기 일치를 확인했다. 단위 테스트는 호출·형식·상태 계약을 검증하며, 장면 의미의 일관성과 모든 속성의 보존은 모델 품질에 의존한다.
