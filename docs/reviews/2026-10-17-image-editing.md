# 이미지 부분 편집 구현 및 검토

- 이미지별 편집은 프롬프트/영역 탭과 같은 행의 불변 이미지 버전을 사용한다. 초안·마지막 탭·원본 좌표계 도구 동작은 [SPEC 19절](../SPEC.md#19-영역-수정), 작성·추론·이력 경계는 [TECH](../TECH.md#영역-수정), 문구 작성 규칙은 [프롬프트 작성 지침](../PROMPT_GUIDE.md)을 따른다.
- 영역 작성은 요청한 가장 작은 대상·부위의 Anima용 쉼표 구분 영어 태그를 작성하고, 주변 묘사는 배치·접합에 필수인 최소 관계로 한정한다. 충분하면 태그 하나로 완결한다. 영역 예제 하나로 부위 한정·기존 속성 보존·간결한 태그 형식을 함께 보여 준다. 전체 작성은 그 결과를 참고해 후속 대화용 장면을 작성한다. 일반 생성·대화 수정·영역 수정 지침은 역할·입력·출력과 범위가 명시된 예시로 구성하며 공통 형식은 영어 프롬프트 본문 한 문단이다. 로컬과 ChatGPT의 태그 검색·진행·소스 저장은 프롬프트 제공자의 공통 추론 경로를 사용하며, 검색 자료도 각 작성 단계의 출력 범위 안에서 선택한다.
- 실행 경계는 일반·영역 생성의 메모리 예약, OOM 한 번 재시도, 취소 검사와 PNG 검증을 공유한다. 워커 클라이언트는 명령별 입력만 구성하고 결과 검증·파일 정리를 공유한다. 캔버스의 획 타입·그리기·PNG 변환은 `regionMask.ts`, 좌표 계산은 `imageViewport.ts`가 담당하며 React 컴포넌트는 도구·포인터·뷰 상태를 관리한다.
- 검증: Python 전체 716개와 Ruff, 프론트엔드 타입 검사와 테스트 204개 통과. 작성 범위 지침·예시와 검색 왕복 후 지침 유지, 작성·검색·소스 저장·이력·분기·합성, 편집 초안·탭·붓·뷰 조작을 확인했다. 일반·영역 명령의 덮어쓰기 방지·잘못된 결과 거부·취소·임시 파일 정리, 영역 OOM 재시도 한도, 실행 직전 취소와 마스크의 알파 기반 이진 변환도 검증했다. 영역 범위 지침 조정에서는 모델/API·GPU·빌드를 실행하지 않았다.
- 모델 확인 기록: RTX 3060, Qwen3.5 4B Q4_K_M, 컨텍스트 4096·출력 2048·thinking medium·시드 42에서 표정 변경과 실제 단보루 조회(후보 8개), 세 번의 작성 추론, 진행·소스·미리보기 일치를 확인했다. 단위 테스트는 호출·형식·상태 계약을 검증하며, 장면 의미의 일관성과 모든 속성의 보존은 모델 품질에 의존한다.
