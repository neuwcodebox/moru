# 프롬프트 실패 원인 표시

최종 프롬프트 누락, 사고 과정 반환, 영어 외 문자 포함, 출력 한도 초과,
응답 중단에 별도 오류 코드를 부여했다. 요청 기록·bridge·한국어/영어 UI에서
원인을 유지하며 출력 한도 초과에는 고급 설정 조정 방법을 안내한다.
분류되지 않은 추론 예외와 과거에 저장된 오류는 기존 일반 오류로 표시한다.
응답 검증·재시도 정책과 의존성은 유지하고 응답 원문·사고 내용은 저장하지 않는다.
표시 계약은 [SPEC](../SPEC.md#11-로딩-및-오류), 구현은 [TECH](../TECH.md#31-구현-및-고정-런타임)에 반영했다.

- 회귀 테스트에서 변경 전 원인이 일반 오류로 합쳐지는 실패 11개를 확인했다.
- Python 일반 테스트 253개, 프런트엔드 테스트 97개, Ruff, TypeScript 검사와 빌드 통과.
- 원인별 분류, 요청 기록과 UI 전달, 부분 프롬프트 제거, 이미지 생성 차단과 동일 요청 재시도를 검증했다.
- Python 검증은 기존 설치 환경에서 `uv run --cache-dir build/uv-cache --no-sync ...`를 사용했다.
- 실제 모델/GPU 추론은 실행하지 않았다. 과거 일반 오류의 세부 원인은 소급 복원할 수 없다.
- 잠금 파일의 inference 의존성으로 Windows portable ZIP `release/Moru.zip`을 빌드했다.
  배포 실행 파일의 숨김 WebView2 UI·설정 저장·클립보드 smoke가 통과했다.
  ZIP 6,377개 항목의 무결성, 최신 UI 포함과 모델·사용자 데이터 제외를 확인했다.
