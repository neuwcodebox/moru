# 모델 수동 다운로드 안내 검토

- 모델 설정에서 준비되지 않은 모델에 `직접 다운로드 하기`를 제공하고, 다운로드 실패 시 자동으로 펼친다. 정확한 파일 이름, 기본 브라우저에서 여는 Hugging Face 파일 페이지와 받은 파일을 `파일 선택`으로 연결하는 방법을 한국어·영어로 안내한다. 한국어 도움말·README·테스트도 같은 문구를 사용한다.
- 링크와 파일 이름은 기존 manifest에서 가져와 자동 다운로드와 동일한 revision을 가리킨다. 공통 모델 3개와 사용할 Anima 버전을 구분하고 두 README에도 파일 목록과 링크를 추가했다. 동작과 구현은 [SPEC.md](../SPEC.md#13-모델-관리), [TECH.md](../TECH.md#14-모델-다운로드)에 반영했다.
- 변경 전 새 Python 테스트 6개와 프런트엔드 테스트 4개의 실패를 확인했다. 변경 후 `uv run pytest` 259개, 프런트엔드 테스트 101개, TypeScript 검사, 프런트엔드 빌드와 Ruff 검사가 통과했다. 두 README의 파일 이름·링크를 manifest와 대조했다.
- 실제 모델 다운로드·GPU 추론과 Windows UI에서 외부 브라우저 실행은 검증하지 않았다. 수동 다운로드도 Hugging Face의 제한을 받으며, 이미 업로드된 포터블 ZIP에는 앱 재빌드가 필요하다.
