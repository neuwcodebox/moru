# 직접 입력 프롬프트

- 입력창과 생성 설정의 프롬프트 작성 모델 선택에 `직접 입력`을 추가했다. 모델 준비에는 설명만 표시한다.
  GGUF나 ChatGPT 계정 없이 사용할 수 있고 선택은 저장되며 접수된 작업은 당시 방식을 유지한다.
- 앞뒤 공백을 제거한 입력을 전체 이미지 프롬프트로 사용한다. 본문·내부 공백·줄바꿈을 보존하며,
  LLM·태그 검색·이력 병합을 생략한다. 후속 요청과 Fork에도 동일하게 적용한다.
  생성 설정에서는 불필요한 작성 옵션을 숨기고 기존 값은 유지한다.
- 영역 수정은 전체 장면 프롬프트 작성이 필요하므로 준비된 로컬 LLM 또는 ChatGPT를 선택하도록 안내한다.
  현재 동작과 구조는 [SPEC](../SPEC.md#34-프롬프트-작성-제공자)과 [TECH](../TECH.md#18-자연어-생성과-세션-분기)에 반영했다.
- 검증: Python 전체 테스트 725개, 프론트엔드 전체 테스트 209개, Ruff, TypeScript 검사와 Vite 빌드 통과.
  직접 입력의 원문 처리·후속 생성·분기·취소·재시도·재생성·재시작 복원·설정 선택을 검증했다.
  실제 모델/GPU 추론은 실행하지 않았다.
