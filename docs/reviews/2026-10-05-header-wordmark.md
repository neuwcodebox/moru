# 헤더 텍스트 로고 정렬

## 변경

- 사용자의 요청에 따라 헤더 이미지 아이콘을 제거하고 `moru` 텍스트만 표시한다.
- 소문자 글리프가 시각적으로 세로 중앙에 오도록 line-height를 1로 설정하고 위로 2px 보정한다.
- 텍스트 로고와 언어 선택 메뉴의 간격을 12px에서 20px로 늘린다.
- 작업 기록 메뉴의 너비 규칙을 `.header-actions select`로 제한한다. 기존 `header select`는
  `.language-select`보다 우선순위가 높아 언어 메뉴의 내용 기준 너비를 덮어쓰고 있었다.
- 제거한 헤더 이미지 스타일과 사용하지 않는 로고 점 스타일을 정리하고 SPEC/TECH를 갱신한다.

## 검증

- 헤더에 `moru` 텍스트와 언어 선택 메뉴가 표시되고 이미지가 없는지 회귀 테스트를 추가했다.
- 해당 테스트 단독 실행 통과, 전체 프런트엔드 테스트 92개 통과.
- `npm run check`와 `npm run build` 통과.
- Windows Chrome headless에서 빌드된 HTML을 1100×800으로 렌더링해 로고의 시각적 높이,
  언어 메뉴와의 간격, 오른쪽 헤더 도구의 배치를 확인했다. 캡처는 `.cache/header-wordmark/header.png`에
  저장했으며 버전 관리에 포함하지 않는다. Python bridge 없이 연결 대기 상태의 헤더를 확인했다.
- jsdom은 글리프의 실제 렌더링 위치를 계산하지 않으므로 시각적 중앙 정렬은 브라우저 캡처로 검증했다.
- Python 코드는 변경하지 않았다.
