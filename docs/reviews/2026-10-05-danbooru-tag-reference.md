# 단보루 태그 지침 반영

제공된 CSV와 공개 분류 자료를 참고해 단보루 태그를 52개 종류·228개로 정리하고
`src/moru/prompt_instructions.py`의 생성·수정 지침에 반영했다. NSFW 관련 종류도
포함하며, 참고표에서 장면에 맞는 어휘를 선택하도록 했다.

요청의 핵심을 유지하면서 조명·배경·질감·구도·스타일을 적절히 보강하는 `ENHANCE`
규칙을 추가했다. 실제 tokenizer 기준 참고표는 693토큰, 생성 지침은 1540토큰,
수정 지침은 1538토큰이다.

전체 일반 테스트 239개를 통과했고 실제 모델 6개 사례를 검토했다.
문장 생략 등 지침 준수의 한계는 남아 있으며 이미지 품질을 검증한 결과는 아니다.
