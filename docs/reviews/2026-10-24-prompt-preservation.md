# 생성 프롬프트 본문 보존

- 로컬 LLM의 개행 기반 강제 EOS와 첫 줄 추출을 제거했다. 로컬·ChatGPT·영역 수정의
  최종 답변은 앞뒤 공백만 제거하고 개행·빈 줄·내부 공백·접두 문구·백틱을 보존한다.
  최종 프롬프트만 출력하도록 하는 책임은 생성 지침에 둔다.
- 로컬 사고 구간은 명시적인 종료 태그로 분리하고, 사고 예산 종료 시 태그와 빈 줄만 생성한다.
  ChatGPT의 commentary는 메타데이터로 구분해 답변·미리보기에서 제외하고 도구 후속 입력에는 유지한다.
  빈 응답·비영어 응답·출력 한도 초과·응답 중단 등 기존 실패 검증은 유지한다.
- 현재 계약은 [SPEC](../SPEC.md#42-이어지는-수정-요청), 구현은
  [TECH](../TECH.md#74-로컬-태그-검색)에 반영했다.
- 검증: 수정 전 코드를 별도 프로세스에 불러 새 회귀 테스트 10개의 실패를 확인했다.
  수정 후 관련 테스트 229개와 Python 전체 일반 테스트 735개, Ruff 및 diff 공백 검사가 통과했다.
  개행 토큰의 강제 종료 방지, 미리보기·이미지 생성·저장·다음 요청의 본문 보존,
  두 제공자의 영역·전체 장면 작성과 commentary 분리를 검증했다.
- 실제 모델/GPU 추론은 실행하지 않았다. 프런트엔드는 변경하지 않았다.
  모델이 지침을 어기고 답변 본문에 붙인 설명도 본문 그대로 보존한다.
- 포터블 빌드: 소스 커밋 `555a6b0`으로 `release/Moru.7z`를 생성했다(2,118,050,490바이트).
  프런트엔드 빌드, 개발 환경을 제외한 실행·UI·설정 저장·클립보드 검사와 7z 전체 무결성 검사가 통과했다.
  모델·사용자 데이터 제외와 실행 파일에 프롬프트 본문 보존 코드가 포함된 것을 확인했다.
  빌드 소스 커밋은 공개 배포 전에 GitHub에 push해야 한다.
